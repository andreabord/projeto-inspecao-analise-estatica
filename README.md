# Sistema de Biblioteca — Inspeção Humana × Análise Estática

Projeto Java deliberadamente preparado para uma atividade de avaliação de qualidade.

## Tarefa
1. Elaborar/adaptar um checklist de inspeção.
2. Realizar inspeção humana das classes.
3. Registrar classe/trecho, categoria, descrição, severidade e recomendação.
4. Executar uma ferramenta de análise estática.
5. Comparar os achados: ambos, somente humano, somente ferramenta e possíveis falsos positivos.
6. Produzir uma análise crítica das limitações de cada abordagem.

O objetivo não é apenas contar alertas, mas interpretar sua relevância.
